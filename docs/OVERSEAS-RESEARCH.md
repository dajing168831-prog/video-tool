# 海外平台方案调研（2026-10-21 · 已暂停）

> 结论：**暂时不做海外**。这份文档留档，将来重启时直接从「验证步骤」往下走，不用重查。

## 一、为什么暂停

| 事实 | 来源 |
|---|---|
| 本机（香港阿里云）海外出口仅 **~1 Mbps** | 实测：Cloudflare 120 KB/s；TikTok 21.4MB 下载 179 秒 |
| 国内带宽 **190 Mbps** | 实测：B站 42.7MB 下载 1.8 秒 |
| 机房 IP 下 TikTok / IG / X **能通** | 实测，解析全部成功（卡的是带宽不是风控） |

一个 20MB 视频要 3 分钟，多人完全不可用 → 海外必须有 ≥50 Mbps 出口，成本没到位。

## 三、调研结果：绝大多数解析 API 对我们没用

**关键矛盾**：解析出直链很容易，难的是「谁付流量钱把文件拉下来」。

| 服务 | 返回什么 | 可用 |
|---|---|---|
| apizero.cn | 文档原话：「返回的媒体地址是第三方 CDN」「这是元数据解析，不存片、不当下载站」 | ❌ |
| 智凌 API（api.17zhiling.com） | 视频直链，文档写明直链有时效 | ❌ |
| TikHub（api.tikhub.io） | 1050 个数据接口，`redirect_download` 只是下它自己的客户端 | ❌ |
| SnapAny（platform.snapany.com） | 1000+ 站点，**代理下载只有 YouTube**（其它站点返回 400 `unsupported_site`） | ⚠️ 不覆盖目标平台 |
| **RenderIO** | `POST renderio.dev/api/v1/ytdlp-download`，下载到 Cloudflare R2，给 signed URL | ✅ 唯一对口 |
| Apify | `download_to_kvs` 模式（下到它的 KV store） | ✅ 备选 |

### RenderIO 细节（唯一验证过的对口方案）

- 覆盖：YouTube / TikTok / Instagram / X / Facebook / Twitch / Reddit / Vimeo + 1000 站
- 18 个地区路由，平均 < 4 秒，零 egress 费
- 价格：
  - Starter $12 —— **不含视频下载器**，用不了
  - Growth $39 → 1000 commands ≈ **333 次视频/月** → ¥0.84/次
  - Business $99 → 20000 commands ≈ **6666 次视频/月** → ¥0.107/次

## 四、重启时必须先过的坎

我在香港测不了，必须在**国内网络**实测。这一条决定方案 B 成不成立。

### 验证步骤（照做）

1. 注册 RenderIO 免费试用（100 次/月）
2. 跑一个 TikTok + 一个 Instagram 链接
3. **在国内网络**下载它返回的 R2 signed URL，记录速度
4. 拉得动 → 后端加 `VT_REMOTE_PARSE_URL`，海外平台转发过去
5. 拉不动 → 回到方案 A（自建海外节点，需 ≥50 Mbps 出口）
