## C01 · 参考剪辑（§2.1 `:181`）

**原文**
> 图1图2图3图4图5图6，严格参考示例视频视频1的镜头节奏、转场风格及音乐。

**输入**：图1–6、视频1
**输出**：多模态参考新1

**句序**
1. 只一句：列举 6 张图 → 声明"严格参考视频1的镜头节奏、转场风格及音乐"

**客观特征**
- 素材用「图N」不用 `@图片N`
- 没有任务类型声明、没有景别、没有约束句
- **"严格参考"的对象是三个具体维度**：镜头节奏 / 转场风格 / 音乐

## C02 · 局部风格化（§2.1 `:182`）

**原文**
> 保持视频1中的建筑、行人和整体环境为真实世界风格不变。仅将视频1画面中的树木、轿车转化为 3D 像素或体素积木风格 (Minecraft style)，风格参考图1。像素化物体的运动轨迹需正常，且保留真实环境的阴影和透射光。整体效果参考视频2。

**输入**：图1 + 视频1 + 视频2

**句序**
1. **先说保什么**：`保持视频1中的建筑、行人和整体环境…不变。`
2. **再说改什么**：`仅将…树木、轿车转化为 3D 像素…风格`，末尾挂 `风格参考图1`
3. **补一条改后要求**：`像素化物体的运动轨迹需正常`
4. **补一条保真要求**：`保留真实环境的阴影和透射光`
5. **总效果锚点**：`整体效果参考视频2`

**客观特征**
- **顺序是「先保后改」**，与 `:192`（先改后保）相反
- 用「仅将」限制改动范围
- 第 3、4 条是**对新生成物体的具体要求**，不是"别动"
- 一条一句话，句号收尾

## C03 · 一镜到底转场（§2.1 `:183`）

**原文**
> @图片1 镜头先快速推进到咖啡表面的奶泡、可可粉颗粒和深色咖啡液体纹理细节，让咖啡表面的颗粒、泡沫和液体涟漪逐渐覆盖全屏，遮挡住其他东西。镜头保持真实微距质感，极浅景深，细小粉末在逆光中缓慢飘落，表面纹理像细沙与流体之间的过渡。避免画面开裂，在咖啡粉颗粒、奶泡起伏、液体旋涡与@图片2 中沙丘沙脊、风蚀纹理、扬沙颗粒高度相似的瞬间，自然无痕转化为沙漠地貌，然后镜头继续向前推进，展示出@图片2 的沙丘全貌。严格避免画面开裂，不要黑屏，不要硬切，不要明显特效，不要拼接感，整体真实、安静、克制，像同一种颗粒材质从咖啡微观表面自然变成宏观沙漠世界。一镜到底，中间不要出现拼接。

**输入**：图1 + 图2

**句序**
1. 从 `@图片1` 出发，写镜头运动 + 画面细节
2. 镜头参数（质感/景深/光线）
3. **转场点**：`在…与@图片2 中…高度相似的瞬间，自然无痕转化为…`
4. **负面清单**：`避免画面开裂，不要黑屏，不要硬切，不要明显特效，不要拼接感`
5. 整体调性 + 最后一句 `一镜到底，中间不要出现拼接`

**客观特征**
- 素材用 `@图片N`
- **开头直接是一个素材**（`@图片1 镜头先…`），没有"@图片1 是什么"的定义句
- 负面约束**写了两次**（第 3 句尾 + 第 4 句首），措辞递进：`避免` → `严格避免`
- 无分段、无标题

## C07 · 多人整体替换（§2.2 `:192`）★ 与复刻双人换人最接近

**原文**
> 参考视频1进行动作模仿。固定机位全景镜头，正视频中三个穿西装的男人替换为三只高度写实的水豚。水豚必须严格遵循原视频的运动轨迹：依次迅速趴到地板上，然后最左边的水豚跳到中间位置，中间位置的水豚翻滚到最左边，接着中间的水豚翻滚到最右边，最右边的水豚跳跃到中间，最后中间水豚跳跃到另外两只背上，堆叠成金字塔形状。保持原有的固定机位不变。确保水豚的毛发质感和光影与环境融合

**输入**：**只有视频1，没有任何图片**

**句序**
1. `参考视频1进行动作模仿。` —— 任务类型声明（第一句）
2. `固定机位全景镜头，` —— 景别 + 机位，**在替换句之前**
3. `正视频中三个穿西装的男人替换为三只高度写实的水豚。` —— 替换句，**整体指代**（共同特征"穿西装"）
4. `水豚必须严格遵循原视频的运动轨迹：…堆叠成金字塔形状。` —— 动作过程
5. `保持原有的固定机位不变。` —— 机位保持
6. `确保水豚的毛发质感和光影与环境融合` —— 融合句（**无句号收尾**）

**客观特征**
- **无图片 ⇒ 整段没有素材说明**（对应 `:248`「没有上传素材时整段跳过」）
- 三个人换同一种动物 → 用「三个穿西装的男人」整体指代，**不逐个点名**
- 替换句用「正视频中…」（此处"正视频中"疑为"视频中"的笔误）
- 保持句**只有两句**：机位 + 融合
- 无分段、无标题

## C11 · 精准换人物与细节（§3.1 `:213`）★ 双人 + 双图

**原文**
> 视频1中最后面的小孩换成 图1中的金毛狗， 视频1中最左边小孩穿的卡其色外套改成图2中的牛仔外套

**输入**：图1 + 图2 + 视频1
**输出**：角色替换1

**句序**
1. **一句话里两个改动，逗号并列**：
   - `视频1中最后面的小孩换成 图1中的金毛狗`
   - `视频1中最左边小孩穿的卡其色外套改成图2中的牛仔外套`

**客观特征**
- **每张图配一个独立的改动对象**，两句都用 `视频1中…` 开头
- 定位词：`最后面` / `最左边`（相对位置，不是九宫格方位）
- 第一个改动用「换成」，第二个用「改成」（换物 vs 换属性）
- **没有**素材说明段、**没有**任务类型声明、**没有**保持句、**没有**融合句
- 两个改动**改的是不同层级**：一个人整个换掉，另一个人只换衣服

## C17 · 多目标 + 台词（§3.4 `:234`）

**原文**
> 参考视频，将视频开头出现的易拉罐饮料替换为可口可乐；背景中原本发光的"全家"便利店招牌修改为"互惠"招牌；视频结尾塑料袋中的所有零食也统一替换为可口可乐易拉罐，最后结尾人物的台词从"买了一些小零食"变成了"买了一堆可乐"

**输入**：视频1
**输出**：高精度指令2

**句序**
1. `参考视频，` —— 开头两个字交代参考
2. `将视频开头出现的易拉罐饮料替换为可口可乐；`
3. `背景中原本发光的"全家"便利店招牌修改为"互惠"招牌；`
4. `视频结尾塑料袋中的所有零食也统一替换为可口可乐易拉罐，`
5. `最后结尾人物的台词从"…"变成了"…"`

**客观特征**
- 前三处用**分号**，第四处转**逗号**接台词
- **每处都带时间/位置限定**：`视频开头` / `背景中原本发光的` / `视频结尾`
- 文字类改动**逐字给出变动前后**

## C18 · 纯文字生成（§3.4 `:235`）

**原文**
> 两位魔术师站在舞台上面向观众表演"互换"魔术： 两人同时挥动魔杖，一阵烟雾升起。烟雾散去后，两人的西装颜色互换——左边的人穿白色西装，右边的人现在穿黑色西装，但两人手套颜色不变。 两人鞠躬致谢，身后的红色幕布拉上，从深红色渐变为深蓝色

**输入**：一张图片（参考板）
**输出**：精准参考魔术师

**句序**
1. 场景 + 动作总起：`两位魔术师…表演"互换"魔术：`
2. 时间顺序推进：挥魔杖 → 烟雾 → 互换结果
3. **互换结果里带例外**：`但两人手套颜色不变`
4. 收尾动作 + 幕布颜色渐变

**客观特征**
- **按时间轴写**，用句号切段，不用时间戳
- 例外约束（手套）**紧贴在被约束的对象后面**，不放到全文末尾
- 完全不用素材引用标记

# 补充：第四节（§四「如何更好地使用 H3」）里的写法规则

> 这一节不是案例表，是**规则表**。19 条功能案例都是短句，真正的**完整提示词范例**在 `§2 特定风格`。

## R1 · 分段是硬要求（`:273`）

> 常见问题：`只写一段话没分段` → 怎么改：`按 3 段公式拆开写`

⇒ **不分段是"坑"**，官方明确要求按 `:244` 的三段公式拆开。

## R2 · 素材必须写用途（`:274`、`:277`）

> `素材上传了但没说用途` → `补一句「@图片1 是 XX 参考」`
> `想要主角脸一致但没传图` → `一定要上传人物参考图，并标注「人物参考」`

## R3 · 切镜怎么保持（`:276` + `:260` + `:254`）

> `想一镜到底但写了很多分镜` → `全文保持一段情节描述，删掉【镜头 N】结构`
> `:260` `切镜的时候可明确写出切镜到什么景别，具体主体是之前的哪个角色，有助于跨镜头一致性的保持`
> `:254` `H3 有基础的分镜能力，以及 H3 对于切镜点遵从较强`
> `:261` `切镜一致性保持：` —— **原文这一条后面是空的**（转写缺失或原文未写）

⇒ 反推：**想要切镜，就要写【镜头 N】/`Shot N` 结构并标"硬切"**；
不写分镜结构 = 默认一镜到底。

## R4 · 17 条功能案例 vs 2 条完整范例

| | 形态 |
|---|---|
| §2.1–§3.4 的 19 条 | 短句，多数**不分段**（一句话能说清的单点编辑） |
| §2 的 2 条（C20/C21） | **完整三段式**，带【整体要求补充】第四段 |

⇒ 分段与不分段不是矛盾，是**任务复杂度**决定的：单点编辑一句话，完整创作才上三段式。

## C20 · 大字幕 MV（§2 特定风格 `:284`）★ 唯一一条"图生视频 + 人物图 + 风格图"的完整范例

**输入**：图1（人物形象）、图2（文字包装样式）、图3（场景视觉风格）
**输出**：两条成片视频

**结构**（四段，全部带 `【】` 标题）

```
【核心创意】
10秒，16:9 横版 trap MV。…（主体/风格/节奏一段话）

【画面过程描述】
Shot 1 — 面部极近特写 / 通道压迫感
- 场景：…参考 @图片3
- 景别：…
- 人物：…
- 文字：…
- 律动：…
- 硬切
Shot 2 — …（同结构）
…
Final — …

【整体要求补充】
▍影像风格（贯穿全片）…
▍文字包装（贯穿全片）…
▍律动规则（贯穿全片）…
▍场景切换（贯穿全片）…
▍景别切换（贯穿全片）…
▍人物规则（贯穿全片）…
▍人物表演（贯穿全片）…
▍重要限制（贯穿全片）…
```

**客观特征**
- **素材说明用冒号式**：`@图片N：用途（具体维度）`，不是 `@图片N 是XX参考`
- **用途后面必须列"取哪些维度"**：`（脸、发型、服装轮廓、比例、气质、整体氛围）`
- **紧跟一条限定句**：`只参考指定维度，不直接复制参考图`
- 段名是【画面过程**描述**】（不是 `:244` 公式里的"说明"）
- 每个 Shot 带 `- 硬切` 标记切点
- 第四段用 `▍` 做子标题，每条标「（贯穿全片）」

# 拆完后的统一分析

> 见下。

## 一、分段：官方要分段（`:273`），但**只有完整创作才上四段**，单点编辑一句话即可

- `:273` 明确把"只写一段话没分段"列为坑
- 但 19 条单点编辑案例**全部**是一句话
- 两条完整范例（C20/C21）才是四段式

⇒ 我们的任务是**单点编辑（换两个人）**，形态上更靠 C11；但我们还有"保持原片动作/机位/光影/切镜"的诉求，那部分更像 C20 的【整体要求补充】。

## 二、素材说明：三种写法并存

| 出处 | 写法 | 场景 |
|---|---|---|
| `:248` | `@图片1 提供了xx角色的形象（如果有多个角色，需要能指代清楚）` | 说明文里的示例 |
| `:264` | `@图片1 是人物参考（锁这位女子的脸）` | 说明文里的示例 |
| `:284` | `@图片3：场景视觉风格（…）` + `只参考指定维度，不直接复制参考图` | **实际范例** |

## 三、切镜

- 想切 → 写 `Shot N` 结构 + `- 硬切`（C20 的写法）
- 想不切 → 删掉【镜头 N】（`:276`）
- **不要写"保持固定机位"**，除非源片本身就是固定机位（C07 的源片是，我们的不是）

## 四、还是空白的两处

1. **音频复用**：`:248` 只有用途词「音频复用（生成视频的音频直接复用参考音频素材）」，**没有任何范例**
2. **`:261`「切镜一致性保持：」后面原文是空的** —— 要么转写丢了，要么官方没写
