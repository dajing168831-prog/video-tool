4 · 方式 2 合法区间（自己算）

两条硬约束，必须同时满足

总像素 宽 × 高 ∈ [921,600, 4,624,220]

宽高比 宽 ÷ 高 ∈ [1/16, 16]

官方原话：总像素是对宽高乘积的限制，不是对宽度或高度的单独限制。

验算我们的两个尺寸

1152×2048 = 2,359,296 ✅ 区间内 · 比例 9:16 ✅

1584×2816 = 4,460,544 ✅ 区间内 · 比例 9:16 ✅

反例 512×512 = 262,144 未达下限 → 报错
