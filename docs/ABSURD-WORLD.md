# 故事世界（World）— 插在建项目和结构卡之间的一步

> 2026-11-07 新增。**不改**十种形态、五拍骨架、C1–C14。
> 只在流程最前面插一步：先定「故事发生在哪个世界」，再走原来的结构。

## 为什么要加

原来的流程：选十种形态之一 → 直接出五拍结构卡。
结果：每条片都是「两个人吵架 → 第三拍掏出商品 → 对方哑口无言」。
换形态、换措辞，故事还是同一个。

实测依据（33 条抖音短剧带货逐帧看完 + 251 条元数据）：

- 33 条里出现了 20 多种**互不重复**的世界：修仙 / 志怪 / 丧尸下乡 / 蔬菜三角恋 / 拖把家族 /
  后宫宫斗 / 农村伦理 / 北欧文艺 / 独占爽文 / 临终病房 / B2B 工厂 …
- 这些世界**没有一个能从商品的品类推出来**——剃须刀拍成北欧文艺片，音箱拍成重生爽文，
  茉莉花茶一条片子里换了 7 个世界
- 但每一个都能指回商品的**一个字面义 / 谐音 / 使用关系**

外部依据：泰国广告的招牌手法是「荒诞 + 洞察」的平衡（ADFEST 2025 现场拆解，
「为什么喜剧是泰国的秘密武器」）；108 条高播放泰国广告里「脑洞逆天」25%、「反转」22.2%、
「幽默」19.4%，**86% 时长超过 1 分钟**。受众调查：煽情走心 80.85% / 搞笑幽默 59.57% /
强烈反差 57.45%。

## 两条路线

| 路线 | 素材来源 | 适用 |
|---|---|---|
| **荒诞** | 从商品本身找联想，不需要外部素材 | 任何商品，随时可用 |
| **煽情** | 这个品类的真实处境 | 需要真材料；没有就只给荒诞 |

⚠️ 煽情路线不得声称「真实故事」——我们没有当事人授权。只提炼**真实处境**，用虚构角色演。

## 三条联想法则（荒诞路线）

| 法则 | 机制 | 怎么找 | 实测样本 |
|---|---|---|---|
| **L1 品类拟人** | 商品/原料变成有性格的角色 | 品类名、外观、用途里找能当「人设」的点 | 蔬菜三角恋、拖把家族争产、燕窝小姐商战、菌菇相亲 |
| **L2 关系裂变** | 使用关系/配方关系 → 人物关系 | 问「它天生和谁配、和谁不配」 | 番茄炒蛋（辣椒插足）、青椒炒月饼（黑暗料理＝包办婚姻） |
| **L3 错位投放** | 商品出现在它绝对不该在的场景 | 问「它最不该出现在哪」 | 旺旺进临终病房、剃须刀拍北欧文艺、Nike 甩进修仙片 |

**判据**：说不出「这个世界从商品的哪个点长出来的」→ 不许用。
「因为更搞笑 / 更抓人」不是理由，那是结果。

## L3 的类型：程序指定，不让模型自己挑（2026-11-08 实测定案）

**结论先行**：L3 每次由程序随机指定**一个具体类型**注入提示词，模型没有挑选余地。

### 怎么试出来的（三轮，共 60 组真实调用）

| 版本 | 做法 | 实测结果 |
|---|---|---|
| A 基线 | 给 15 个类型名，模型自己挑 | 塌缩：丧尸 4 / 武侠 4 / 宫廷 2（10 商品） |
| B 禁令 | A + 「这三类少用」 | **只是换个塌缩点**：志怪 5 / 默片 2 |
| C 给族 | 程序挑族（如"古装传奇"），模型在族内挑 | **族内塌缩**：现实类型剧 6 条里 5 条豪门争产 |
| **D 指定唯一类型** | 程序随机指定「宫廷」「西部片」「皮影戏」等 | **10 商品 10 个不重复类型，平均 4.6 分，无一硬凑** |

D 的关键验证是**最不搭的 6 个组合**（木偶戏×剃须刀、星际×口红、丧葬民俗×猫粮、宫廷×拖把、
西部片×卫生巾、都市情感×钙片）：4 个五星、1 个四星、1 个三星。
木偶趁老师傅睡着刮自己不存在的胡须、深空货船里「显白＝发亮＝暴露」、义庄祖训「尸身不腐者方可入祖坟」，
都比「搭」的组合更好。**不搭不是风险，是这次要的东西。**

### 类型池（30 个，`_L3_GENRES`）

古装传奇：宫廷 / 仙侠 / 武侠 / 志怪 / 民国
类型影视：悬疑片 / 恐怖片 / 西部片 / 犯罪片 / 欧美文艺片
民间怪谈：丧葬民俗 / 乡村怪谈 / 都市传说 / 庙宇 / 老宅
非写实：皮影戏 / 木偶戏 / 定格动画 / 默片 / 二维动画
未来科技：赛博朋克 / 星际 / 科幻 / 人工智能 / 虚拟现实
现实类型剧：豪门争产 / 家庭伦理 / 职场剧 / 校园剧 / 都市情感

### 已剔除的三个（都有实测理由）

- **末日丧尸**：4 次实测全是同一套「末日里只有它还有用」，换成科幻/星际/赛博后同商品明显变好
- **重生 / 穿越**：这不是「世界」，是叙事装置（主角记得前世），场景仍是现代现实 →
  模型只能硬塞，剃须刀×重生出了「干净＝重来一次要守住的东西」这种牵强来路

### 已知弱项（1 个样本，先记着）

**都市情感**（卫生巾 × 离婚律政，★★）：和重生同一个毛病——太泛、不构成错位，商品本来就在现实里。
再出现一次就换成更硬的类型（谍战 / 年代剧）。家庭伦理同理，待观察。

## 顾客自己挑类型（2026-11-08）

主人定：这一屏给顾客看到的不是技术标签，而是**「你想把这个产品，拍成什么片？」**

- 页面列出 6 类 30 个类型（`GET /world-genres`，前端不自己存一份）
- 点一个类型 → 三个候选**全部落在这一类型里**（不是只有 L3）
  - L1 把商品变成这个世界里有身份的角色
  - L2 把「谁配它、谁克它」变成这个世界里的人物关系
  - L3 直接把它扔进这个世界
- 不挑 → 走原来的：L1/L2/L3，L3 由程序随机指定一个类型
- 卡片上不再显示 `L1/L2/L3`，翻成「让商品当主角 / 拿关系做文章 / 把它扔错地方」

**实测（指定类型后三条是否都在那一类）**：口红×宫廷 3/3（尚服局成精的老口脂 / 敬事房验盏留红降位 /
浣衣局宫女嘴上洗不掉的正红）；卫生巾×西部片 3/3（白棉大王进镇 / 女赏金猎人共骑一匹换不了衣裳的马 /
理发师柜子里只给最贵伤员的夜用加长）。

## 接口

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/drama/world-genres` | 可挑的短剧类型（6 类 30 个），前端照它渲染 |
| POST | `/api/drama/projects/{pid}/worlds` | 出候选。`{route: "荒诞"｜"煽情"｜"", genre: ""｜"宫廷"…}` |
| POST | `/api/drama/projects/{pid}/world` | 选中。写入 `answers.world / world_from / world_law / route` |

## 注入方式

`_world_block(doc)`：只在 `answers.world` 非空时注入，插在结构卡和剧本两处提示词最前面。
**空 = 老流程一个字不改。**

## 与老线的关系

- 老线：`D:/skills/product-drama`（十形态 + 五拍）**一个字没动**
- 本文件只描述「前面这一步」
- 十种形态照旧可选；选了世界只是让整条片发生在那个世界里，结构还是原来的结构

## 素材来源：只有模型调研，不接截流

**煽情路线不抓评论。** 理由：每次生产都去平台抓 = 必然触发风控；离线攒库又会长期缺品类。

改为**模型调研**，一次调用完成两步：

1. **调研**：购买时刻 / 买完的真实情况 / 8 条假设的用户原话
2. **提炼**：从调研里挑 3 个能演成戏的处境

🔴 **合规边界**：调研产出的「用户原话」是**假设**，不是真实评论。
- 只存在项目 json 里（`world_research`），给写戏用
- 不展示成「用户说」，不进成片字幕，不对外声称是真实反馈

## 已知缺口

- 三个候选里只有 L3 一个是类型片世界，L1/L2 仍是「拟人」「关系」两类。
  顾客一次只能看到一个类型片，要换类型得点「换一批」。（是否改成一次给两个不同类型，等主人定）
- 商品角色 `role` 后端默认「转折道具」，顾客没选也会写进结构卡 —— 已知的硬编码束缚。
- 「都市情感 / 家庭伦理」这两个类型偏泛，只测了 1 次（★★），再出一次弱项就换掉。
