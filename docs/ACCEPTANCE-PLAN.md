## 3. 记账规则

1. **一条片子一个 render id**，写进 `CAPABILITY-LEDGER.md` 对应行的状态列（🟡 → ✅ + id）。
2. **失败了不是删单**：写进 `OPEN-DEFECTS.md`，按「现象 / 涉及通道 / 根因 / 状态」四列。
3. **一次只改一个变量**：同一制片子只动一个开关，否则只能记事实、不能记归因（`FEATURE-MAP` §7）。
4. **看不清就别判**：480p 截图看脸不可靠（2026-10-25 我判错过两次）——
   用结果页的身份核对数字，或抽帧放大再看。
