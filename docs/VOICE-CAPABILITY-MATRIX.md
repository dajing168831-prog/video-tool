## 三、缺口清单（**不做价值排序**）

🩸 **2026-11-05 教训**：我第一版按"感觉"排了个名次，把「音频生成」排第一，理由是
「成片只有人声、没有音效/BGM」——**这个前提是错的**。我们早就有
`_separate_tracks` + 三维音轨开关 + `fit_loop` + `merge`（见 §二），
前端「保留原声/全新配音/配音+背景音」「保留原片/不要背景音乐/换成我上传的」
全部有后端实现。真实情况只是「不能用 AI **从零生成**新音效」。

排序需要证据（用户投诉、失败任务、行为数据），不是我拍脑袋。下面只列事实：

| 缺口 | 官方能力 | 现状 |
|---|---|---|
| A2 SSML | 停顿/多音字/数字读法 | 台词按原文念，特殊读法靠改字 |
| A3 文本过滤 | markdown/emoji/LaTeX 过滤 | 台词是纯文本，暂不需要 |
| A11 `context_texts` | 自然语言控语气/语速，文字不计费 | 只能靠音色+语速，复刻音色用不了 |
| A12 发音词典 | 纠正多音字/人名 | 念错只能改台词 |
| A13 `enable_subtitle` | 字级时间戳（仅中英） | 要做字幕得另跑 ASR |
| A14 音色设计 | 文字/图片生成音色 | 只能选现成或复刻 |
| A15 音频生成 | AI 从零造音效/BGM（≤120s） | 原片音效可复用，缺的是"素材本身没声音"的场景 |
| A16 异步长文本 | ≤10 万字符 | 台词短，用不上 |
| A17 `aigc_metadata` | 隐性水印 | 红线：默认不打 |
| B3 音色升级 | V1→V3 | 我们直接用 V3 |
| C2/C3 流式识别/声纹 | 实时识别、说话人区分 | 当前只用录音文件识别 |

## 四、已知边界（别当成 bug）

1. **2.0 没有 `emotion` 参数**。1.0 有（`1257544:527`），2.0 接口整篇没有。
2. **12 个口音音色里 11 个是 1.0**（`_moon_bigtts`/`_mars_bigtts`），现行 HTTP 接口只开放 `seed-tts-2.0`/`seed-icl-2.0`。
3. **`context_texts` 不适用于复刻音色**（`2528925:150`、`:260`）。
4. **`tone_fidelity` 不支持跨语种、不支持双向流**（`2528925:16-21`）。
5. **`enable_subtitle` 只支持中英文**（`2528925`）。
