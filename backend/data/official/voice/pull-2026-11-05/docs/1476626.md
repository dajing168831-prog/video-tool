## Requests #

| 参数 | 类型 | 是否必须 | 说明 | 示例 |
|---|---|---|---|---|
| AppID | string | 是 | 应用ID，通过应用列表获取，应用和账号有从属关系校验 | 10000000 |
| ResourceID | string | 是 | 详见附件 | volc.service_type.10029 |
| Start | date | 是 | 查询起始时间，仅支持yyyy-MM-dd 格式 | 2024-08-15 |
| End | date | 是 | 查询结束时间，仅支持yyyy-MM-dd 格式 | 2024-08-15 |
| Mode | string | 否 | 查询模式，支持按天和按小时维度查询： daily/hourly/minutely/5 minutely，默认为daily建议：​按1分钟或者5分钟查询的时候，时间范围不超过1天；按小时查询的时候，时间范围不超过7天；按天查询的时候，时间范围不要超过7天。 | hourly |

## Response #

| 参数 | 类型 | 是否必须 | 说明 | 示例 |
|---|---|---|---|---|
| status | string | 否 | 响应状态，成功或失败 | success |
| data | object | 否 | 响应数据 | 详见下面示例部分 |
| quota_monitoring | array | 否 | quota监控结果，如果无数据，则为null | 详见下面响应示例 |
| day | string | 是 | 查询日期维度指标 |   |
| value | int | 是 | 指标具体的用量，可能为qps/并发 |   |
| limit | int | 是 | quota的最大值，服务开通和购买时候可见的qps/concurrency的值 |   |
| error_message | string | 否 | 如果有错误的话，会展示出此字段 |   |
