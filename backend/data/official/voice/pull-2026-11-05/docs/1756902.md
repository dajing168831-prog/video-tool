| Key | 说明 | 参数类型 | 是否必须 | Value示例 |
|---|---|---|---|---|
| X-Api-Key | 使用火山引擎控制台获取的API Key，可参考 控制台API Key管理 | string | 必须 | "your-api-key" |
| X-Api-Resource-Id | 表示调用服务的资源信息 ID，是固定值 | string | 必须 | volc.service_type.10053 |

若使用旧版控制台，鉴权方式如下。建议尽快切换至新版，以体验更便捷的鉴权流程。

|---|---|---|---|---|

#### 发送音频数据-TaskRequest
