###### 豆包语音

豆包语音

- 文档首页
| 字段 | 含义 | 层级 | 格式 | 必需 | 备注 |
|---|---|---|---|---|---|
| app | 应用相关配置 | 1 | dict | ✓ |   |
| appid | 应用标识 | 2 | string | ✓ | 根据不同业务线提前申请 |
| token | 应用令牌 | 2 | string | ✓ | 由平台提供 |
| cluster | 业务集群 | 2 | string | ✓ | 后端集群 |
| user | 用户相关配置 | 1 | dict | ✓ |   |
| audio | 音频相关配置 | 1 | dict | ✓ |   |
| voice | 发音人 | 2 | string | ✓ | other |
| voice_type | 输出音频音色类型 | 2 | string | ✓ | 音色列表 |
| encoding | 输出音频编码格式 | 2 | string |   | wav/pcm/mp3/ogg_opus，默认为pcm |
| rate | 输出音频采样率 | 2 | int | ✓ | 支持16000/24000/32000/48000 |
| pitch_ratio | 调整音调 | 2 | float |   | 范围[0.1-3.0]，默认1.0 |
| volume_ratio | 调整音量 | 2 | float |   | 范围[0.1-3.0]，默认1.0 |
| request | 请求相关配置 | 1 | dict | ✓ |   |
| reqid | 请求ID | 2 | string | ✓ | 每个请求需要保证唯一性 |
| operation | 操作 | 2 | string | ✓ | submit |
| sequence | 序号 | 2 | string | ✓ | 分包序号，从1开始，最后一包为负值 |
| with_vc_sing | 模式选择 | 2 | bool |   | 默认值为false语音模式；值为true则为语音模式，但对于不支持歌唱模式的音色会依然使用语音模式。 |
