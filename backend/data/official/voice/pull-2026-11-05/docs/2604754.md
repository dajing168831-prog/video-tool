*音频来源 
*语音识别 SDK 支持以内置录音机、外部 PCM 音频流或音频文件作为输入，配置值分别为：
*SpeechEngineDefines.RECORDER_TYPE_RECORDER，内置录音机；
*SpeechEngineDefines.RECORDER_TYPE_STREAM，外部 PCM 音频流；
*SpeechEngineDefines.RECORDER_TYPE_FILE，PCM 格式的音频文件。
*

*大模型ASR相关参数需要通过 PARAMS_KEY_ASR_REQ_PARAMS_STRING 配置传入，以下用设置VAD切句、热词表为例，其它参数同理（BigASR相关参数可参考：语音识别API文档）。

*注：若要输出语音停顿、分句、分词信息，需先设置 PARAMS_KEY_ASR_SHOW_UTTER_BOOL 为 true。

*发送指令
*语音对话 SDK 通过发送指令接口 sendDirective 触发各种操作，需要注意不建议在 SDK 的回调线程中调用该接口。
*启动引擎
*启动引擎前调用SYNC_STOP指令，保证前一次请求结束。
