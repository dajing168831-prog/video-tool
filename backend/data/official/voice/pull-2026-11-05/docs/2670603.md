*本接口提供长文本语音合成能力，专为长文本、非实时场景设计，采用异步任务模式执行合成。客户端调用 submit 接口提交合成任务后，通过轮询 query 接口查询任务状态；音频合成完成后，query 接口将返回合成音频的下载链接
*说明
*最大单次支持 10 万字符的文本输入，当文本中非法字符占比超过 10% 时，接口将返回错误，任务不予执行，需修正后重新提交；非法字符指 ASCII 码中的控制字符（不含制表符 \t 和换行符 \n）
*合成音频在服务端可保存 7 天，过期后将被清理。音频下载链接的有效期为 1 小时，若链接失效，请重新调用 query 接口获取最新下载地址
