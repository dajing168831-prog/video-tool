*概述
*本接口提供音频声纹（Speaker Embedding）的全生命周期管理服务，支持声纹注册、信息更新、删除、批量查询与分页列表等操作。
*说明
*每个 App ID 最多支持注册 100 万条声纹。注册时需上传 5～30 秒的音频，支持格式：wav、pcm、mp3。
*声纹分组数量无上限，但每个分组最多支持 50 条声纹。
*基本信息

*鉴权方式
*以下两种方式二选一，在请求 Header 中携带：
*方式一：API Key
*X-Api-Key: {your_api_key}
*方式二：App ID + Access Key
*X-Api-App-Id: {your_app_id} 
*X-Api-Access-Key: {your_access_key}
*说明
*API Key 为新版控制台鉴权方式，可从 控制台>API Key管理 获取。同时支持旧版控制台的鉴权方式，详见旧版控制台鉴权参考示例

*1. 更新声纹（UpdateVoiceprint）
*POST https://openspeech.bytedance.com/api/proxy/invoke?Action=UpdateVoiceprint
*通过请求体中的 Action 字段区分操作类型：创建、更新或删除声纹。
*请求参数
*
*Action 取值说明
*
*请求示例
*创建声纹（Action=0）
 
*更新名称（Action=1）
 
*更新音频并重新提取 embedding（Action=1）
 
*删除声纹（Action=2）
 
*响应示例
 
*业务逻辑说明
*创建声纹时会校验注册数量上限，默认上限为 100w条，可通过 TCC 配置 audio_embedding_conf 调整。
*音频会被转换为 16kHz PCM 格式（采样率可配置），embedding 由 SAMI 模型服务提取。
*删除操作为软删除，已删除记录不会在 Get / List 接口中返回。
