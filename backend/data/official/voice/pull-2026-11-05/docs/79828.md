注意

最新版的 SDK 已经支持按照符合直觉的方式来设置语速、音高和音量，例如语速配置为 1.5 就表示 1.5 倍速。下文中介绍的映射关系只在 SDK 的早期版本中有效。

因为一些历史遗留问题，语音合成的语速、音高与音量三项配置不能直接配成直观可理解的值，配置值与可理解的值之间具有一定的映射关系。

## 语速的映射关系 #

### 转换公式 #

实际语速 = 0.05 * (配置语速) + 0.5

### 映射表 #

| 配置语速 | 实际语速 |
|---|---|
| -10 | 0 |
| 0 | 0.5 |
| 10 | 1 |
| 20 | 1.5 |
| 30 | 2 |
| 50 | 3 |

## 音高的映射关系 #

### 转换公式 #

实际音高 = exp(0.69314718056 * (配置音高 - 10) / 12)

### 映射表 #

| 配置音高 | 实际音高 |
|---|---|
| -2 | 0.5 |
| 10 | 1 |
| 17 | 1.5 |
| 22 | 2 |

## 音量的映射关系 #

### 转换公式 #

实际音量 = 配置音量 / 10.0
