接口地址：open.volcengineapi.com 请求方式：GET 认证方式：可直接查看示例代码计算方式

## Requests #

| 参数 | 类型 | 是否必须 | 说明 | 示例 |
|---|---|---|---|---|
| AppID | string | 是 | 应用ID，通过应用列表获取，应用和账号有从属关系校验 | 10000000 |
| ResourceID | string | 是 | 详见附件 | volc.service_type.10029 |
| Start | date | 是 | 查询起始时间，仅支持yyyy-MM-dd 格式 | 2025-02-23 |
| End | date | 是 | 查询结束时间，仅支持yyyy-MM-dd 格式 | 2025-02-25 |
| Mode | string | 否 | 查询模式，支持按天维度查询：daily | daily |

## Response #

| 参数 | 类型 | 是否必须 | 说明 | 示例 |
|---|---|---|---|---|
| status | string | 否 | 响应状态，成功或失败 | success |
| data | object | 否 | 响应数据 | 详见下面示例部分 |
| usage_monitoring | array | 否 | 调用量监控结果，如果无数据，则为null | 详见下面响应示例 |
| day | string | 是 | 查询日期维度指标 |   |
| value | float | 是 | 具体的调用量 |   |
| error | string | 否 | 如果有错误的话，会展示出此字段 |   |
