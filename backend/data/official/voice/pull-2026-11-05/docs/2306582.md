*模型能力介绍
*豆包机器翻译模型是一款通用高质量的多语言文本翻译模型。目前已支持32种语言互译，提供最忠实、最地道、最流畅的译文，深度优化视频、办公、电商、游戏、社交等领域，在对外商用前已获得广泛应用和落地。
*产品核心优势
*翻译质量更强：更准、更自然
*在多个公开的多语种测试集上，翻译质量评估表现领先。可实现难例能翻对、语气自然、关键点不丢失，不仅关注客观指标，更关注人类感知。
*更懂语境：紧贴真实业务场景
*  豆包机器翻译模型经历了内部研发 → 重点场景验证 → 业务落地的迭代过程。两个典型场景：
*短视频翻译：该场景的特点是短文本、口语化、情绪强、符号/表情/梗多，豆包机器翻译模型在标题、评论、贴纸等场景达到较高平均分（3.5–4分/满分4分）；
*办公翻译：该场景特点是对话省略多、礼貌表达多、跨团队协作语境强、术语密度高。在英中等高频语向对话、科技型文档、会议口语等方面显著优于传统翻译模型。
*复杂表达处理更合适
*在真实业务里，最常见的问题不是“不会翻”，经常出现：直译导致偏义/不自然、忽略语境、省略不补全、语气不匹配等问题，豆包机器翻译可实现：
*在不改变原意的前提下做必要的结构调整（语序/从句拆分/补全省略）；
*用目标语言更自然的等价表达替代“逐词对应”的直译；
*对 IM/社交文本识别“意图”（致谢/请求/提醒/委婉表达）并正确表达。
