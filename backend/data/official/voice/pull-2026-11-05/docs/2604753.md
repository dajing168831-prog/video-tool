*基于大模型流式语音识别接口，支持音频流式输入、识别结果流式输出，低时延，适用于实时语音识别场景，覆盖多语种与多方言，以下为面向开发者的iOS SDK接入说明。
*SDK版本
*iOS：pod 'SpeechEngineToB', '0.0.15.0'
* 
*示例demo
*主要参考BigAsrViewController
* 
*兼容性
**
*调用流程
*初始化环境依赖
*创建语音对话 SDK 引擎实例前调用，完成网络环境等相关依赖配置。APP 生命周期内仅需执行一次。
* 
*创建引擎实例
*语音对话 SDK 通过如下方式获取相关实例。
* 
*参数配置（必要）
* 
*音频来源 
*语音识别 SDK 支持以内置录音机、外部 PCM 流或音频文件作为输入，配置值分别为：
*SE_RECORDER_TYPE_RECORDER，内置录音机；
*SE_RECORDER_TYPE_STREAM，外部 PCM 流；
*SE_RECORDER_TYPE_FILE，PCM 格式音频文件。
* 
* 
*设置最大录音时长，当达到设置的时间后，会发送音频结束包并等待asr结果
* 
*参数配置（可选）
* 
*大模型ASR参数配置
*大模型ASR相关参数需要通过 SE_PARAMS_KEY_ASR_REQ_PARAMS_STRING 配置传入，以下用设置VAD切句、热词表为例，其它参数同理（BigASR相关参数可参考：语音识别API文档）。
* 
*注：若要输出语音停顿、分句、分词信息，需先设置 SE_PARAMS_KEY_ASR_SHOW_UTTER_BOOL 为 true。
*初始化引擎实例
*初始化引擎对象并设置回调监听。
* 
*发送指令
*语音对话 SDK 通过发送指令接口 sendDirective 触发各种操作，需要注意不建议在 SDK 的回调线程中调用该接口。
*启动引擎
*启动引擎前调用SYNC_STOP指令，保证前一次请求结束。
* 
*注意：当音频来源为 RECORDER_TYPE_STREAM 时，启动引擎前需要自行启动 APP 层的录音机。当音频来源为 FILE 时，需要设置音频文件路径：
* 
*结束音频输入-FinishTalking
*如果是按住说话模式，松手后调用 FinishTalking 结束音频输入，等待最终识别结果。
* 
*停止引擎
* 
*回调接收返回数据
*启动引擎后，SDK会不断回调消息。
* 
*回调消息说明
**
*销毁引擎实例
*当不再需要语音识别后，建议对引擎实例进行销毁，释放内存资源。
