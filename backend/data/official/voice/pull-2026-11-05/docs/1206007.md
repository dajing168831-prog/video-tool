## 使用流程 #

#### 第一步：创建应用

在火山引擎控制台-豆包语音中成功创建应用并开通服务

#### 第二步：创建替换词

- 进入控制台-豆包语音模块
- 左侧管理栏进入自学习平台-替换词管理
- 点击添加替换词文件创建新的替换词表
- 在左侧弹窗中输入替换词文件名称、替换词内容,我们同时提供您通过文件上传和文本输入的方式来编辑需要优化的替换词文件内容,点击提交创建词表l
- 每一个替换词文件会生成对应的替换词ID,您可以通过复制按钮复制ID,在识别请求中传入id来生效对应的替换词文件
- 创建完成的替换词可以查看详情、修改和下载对应的文件
- 同时您可以通过右上角切换应用来切换维护不同应用下的替换词文件
#### 第三步：接口调用

- 在请求语音识别相关服务时，传入id为替换词 ID
- 在请求字幕识别服务时，除了替换词 ID 还需要传入asr_appid为当前 appid
- 详细使用方法见 API 接口文档： 大模型流式语音识别API语音识别API接入文档：音视频字幕生成API接入文档
- 大模型流式语音识别API

- 音视频字幕生成API接入文档
## 使用限制 #

- 目前支持中英文的替换词优化
- 标准替换词表上传支持TXT格式，UTF-8编码格式
- 正则词表与术语词表上传json文件
- 替换词不支持除换行和空格之外的标点符号
