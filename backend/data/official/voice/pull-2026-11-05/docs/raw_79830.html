SDK 版本号含义 #

当前 SDK 所支持的离线合成存在几个有明显区别的方案：v2, v4, v5. 其中 v2 已经不再迭代也不再推荐使用；v4 是当前最稳定的版本；v5 是效果最好的版本。
并不是每个 SDK 组件都支持 v2, v4 和 v5, 为了能体现出 SDK 与其所支持的离线合成方案之间的关系，在 2023 年 8 月我们修改了 SDK 的版本号规则，后续发布的 SDK 就能根据组件版本号来区分其所支持的离线合成方案。
SDK 组件版本号规则为 max.min.x, 其中max表示所支持的最高版本的离线合成方案，min表示所支持的最低版本的离线合成方案，x 和离线合成方案没有关系，只是一个从 0 开始递增的数字。例如
