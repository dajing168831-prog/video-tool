*Q2：如何监控所购买资源包使用情况？快到期或快使用完是否有提醒？
*资源包用量：进入「用量统计」页面，选择对应项目、对应项目下的模型，可查看固定日期内的模型用量情况
*资源包额度：进入「我的资源」页面，可查看资源包剩余额度
*用量提醒：在页面右上角点击进入“消息接收配置”，可根据需求选择“自动续费提醒”“资源包余额预警”等通知形式

*Q3：下图所示服务“关停”、“回收”是什么意思？要怎么恢复使用？
*按调用后付费实例会出现欠费关停和回收状态，说明如下：
*自账户欠费起2个小时仍未能补缴所有欠费账单，保留该实例并关停服务
*欠费168小时内补缴所有欠费账单后，服务将恢复正常
*当欠费超过168小时，视为主动放弃该服务，资源将被释放且无法恢复
*解决方案：
*打开费用中心-账单管理-账单详情，查看是否欠费
*关停状态-已欠费，从欠费之时起168小时内补缴所有欠费账单后，服务将自动恢复正常；
*回收状态-已欠费，该服务实例无法恢复，补缴欠费账单后，可创建一个新的应用服务，并再次开通使用。
