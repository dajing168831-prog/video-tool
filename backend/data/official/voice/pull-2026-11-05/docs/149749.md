自动字幕打轴功能整体处理流程分为三个阶段：

- 客户端抽取视频中音轨，转成音频文件；
- 把音频文件和字幕文本发送至后端集群，获取任务 ID；
- 通过任务 ID 访问后端接口获取结果。

| cluster | 请求集群 |   | ata_cluster（固定传入值） |
