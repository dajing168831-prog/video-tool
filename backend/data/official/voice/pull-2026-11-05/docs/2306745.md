*术语词概述 
*可应用于豆包同声传译、豆包机器翻译模型，可配置术语词对，提升已配置术语词翻译的准确率。
*使用流程 
*第一步：创建应用
*在火山引擎控制台-豆包语音中成功创建应用并开通服务
*第二步：创建术语词
*进入控制台-豆包语音模块
*左侧管理栏进入自学习平台-术语管理
*点击添加术语词文件创建新的术语词表
* 
*
*在左侧弹窗中输入术语词文件名称、术语词内容,我们同时提供您通过文件上传和文本输入的方式来编辑需要优化的术语词文件内容,点击提交创建词表
* 
*
*每一个术语词文件会生成对应的术语词ID，您可以通过复制按钮复制ID，在识别请求中传入id来生效对应的术语词文件
* 
*创建完成的术语词可以查看详情、修改和下载对应的文件
*同时您可以通过右上角切换应用来切换维护不同应用下的术语词文件
* 
*
*第三步：接口调用
*在请求语音识别相关服务时，传入id为术语词 ID
*详细使用方法见 API 接口文档：
*同声传译2.0-API接入文档
*豆包机器翻译模型-API接入文档
*
*使用限制 
*术语词表上传支持 json 文件，内容格式为 json 对象，例如 {"xx":"yy"}
*术语词不支持除换行和空格之外的标点符号
