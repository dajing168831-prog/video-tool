语音播客
文档反馈
问问助手
支持基于文本、网页或话题生成双人播客音频​
接入前，请阅读接入必读文档​
​
POST https://openspeech.bytedance.com/api/v3/podcast/sse​
​
请求头​
x-api-key string 必选​
API Key 可以从 控制台>API Key管理 获取​
​
x-api-resource-id string 必选​
请求的模型版本​
固定值：volc.service_type.10050​
​
Content-Type string 必选​
固定值：application/json​
​
Accept string​
指定服务端以 SSE 流式返回响应​
固定值：text/event-stream​
​
x-api-request-id string​
用于链路追踪的ID；未传时会自动生成，并在响应头返回​
​
​
请求体​
action number 必选​
指定播客生成方式。​
0：根据 input_text 或 input_info.input_url 总结生成；​
3：根据 nlp_texts 中的对话文本直接合成；​
4：根据 prompt_text 指定的话题联网生成。​
默认值 0​
​
input_text string​
用于总结生成播客的原文。​
注意：​
  • 当 action=0 时，该参数与 input_info.input_url 至少填写一项​
  • 当 action=0 时，若同时填写了该参数与input_info.input_url，优先使用 input_text。​
​
prompt_text string​
指定联网生成播客的话题。​
例如：“火山引擎”“怎么平衡工作和生活？”​
注意：​
  • 当 action=4 时，需填写该参数​
  • 不支持指令控制​
​
nlp_texts object​
待合成的播客对话列表，每项包含一轮对话的 text 和 speaker。​
注意：当 action=3 时，需填写该参数​
text string​
当前轮次的对话文本。单轮不超过 300 字符，所有轮次合计不超过 10000 字符。​
​
speaker string​
指定当前轮次的音色 ID。包括以下音色：​
  • 黑猫侦探社咪仔（默认）​
  • zh_female_mizaitongxue_v2_saturn_bigtts​
  • zh_male_dayixiansheng_v2_saturn_bigtts​
  • 刘飞和潇磊​
  • zh_male_liufei_v2_saturn_bigtts​
  • zh_male_xiaolei_v2_saturn_bigtts​
  • 语音合成音色​
  • 声音复刻接口生成的音色​
​
​
input_info object​
input_url string​
用于生成播客文本的网页或文件链接，文件须可下载，支持 pdf、doc、txt。​
注意：当 action=0 时，该参数与 input_text 至少填写一项。​
​
only_nlp_text bool​
是否仅输出播客对话文本列表，不输出音频。​
默认值：false​
​
return_audio_url bool​
是否返回完整播客音频的下载链接，有效期 24 小时。​
注意：下载链接位于Event 363（PodcastEnd）的 meta_info.audio_url​
​
input_text_max_length int​
模型处理的最大字符数。​
注意：当 action=0 时生效，超出部分自动截断。建议不超过 12000 字符，以保证稳定性。​
默认值：20000​
​
max_char_length_per_round int​
每轮合成字符数上限。优先在句号（。）等句末标点处断句，保证语句完整后再检查字符数，不强制截断。​
默认值：300​
​
strict_audit bool​
安全审核等级​
true: 严格审核​
false：普通审核​
默认值：false​
注意：该参数对 action=0 的 input_text 和 action=4 的 prompt_text 生效。​
​
​
use_head_music bool​
是否使用开头音效。​
默认值：true​
​
use_tail_music bool​
是否使用结尾音效。​
默认值：false​
​
aigc_watermark bool​
是否启用显式水印，开启后在音频结尾添加节奏标识。​
默认值：false​
​
*aigc_metadata object *隐式水印配置，在音频文件头中写入元数据。 *注意： *水印支持 mp3、wav、ogg_opus格式 *本接口可输出的音频格式以format为准 * * * * * *enable bool *是否启用隐式水印。 *默认值：false *content_producer string *合成服务提供者的名称或编码。 *produce_id string *内容制作编号。 *content_propagator string *内容传播服务提供者的名称或编码。 *propagate_id string *内容传播编号。
aigc_metadata object​
隐式水印配置，在音频文件头中写入元数据。​
注意：​
  • 水印支持 mp3、wav、ogg_opus格式​
  • 本接口可输出的音频格式以format为准​
enable bool​
是否启用隐式水印。​
默认值：false​
​
content_producer string​
合成服务提供者的名称或编码。​
​
produce_id string​
内容制作编号。​
​
content_propagator string​
内容传播服务提供者的名称或编码。​
​
propagate_id string​
内容传播编号。​
​
​
audio_config object​
输出音频配置。配置音频参数有助于减少服务端音频解码耗时。​
format string​
指定输出音频格式。​
可选值：mp3、ogg_opus、pcm、aac​
默认值：pcm​
​
sample_rate number​
指定输出音频采样率，单位 Hz。​
可选值：16000、24000、48000​
默认值：24000​
​
speech_rate number​
指定语速，取值范围 [-50, 100]。​
-50 为 0.5 倍速，100 为 2.0 倍速；超出范围时自动调整为对应边界值。​
默认值：0​
​
​

speaker_info object​
发音人配置。​
random_order bool​
是否随机选择先开始说话的发音人。​
默认值：true​
​
speakers []string​
播客音色 ID 列表，仅支持 2 位发音人。​
可选音色如下：​
  • 黑猫侦探社咪仔（默认）​
  • zh_female_mizaitongxue_v2_saturn_bigtts​
  • zh_male_dayixiansheng_v2_saturn_bigtts​
  • 刘飞和潇磊​
  • zh_male_liufei_v2_saturn_bigtts​
  • zh_male_xiaolei_v2_saturn_bigtts​
  • 语音合成音色​
  • 声音复刻接口生成的音色​
​
speaker_additions map[string]string​
音色附加配置，适用于语音合成音色、声音复刻音色。请参考语音合成接口配置自定义附加参数（req_params.additions）​
示例：​
​
{​
"S_speaker_name": "{\"model\": \"seed-tts-2.0-standard\"}"​
}​
​
​
​
*retry_info object *连接中断后继续生成 * * * *retry_task_id string *待续传的原任务 ID，填写首次请求响应中的 session_id *注意：续传会生成新的 session_id，但多次续传仍使用首次请求的值 *last_finished_round_id number *最后完整接收的轮次 ID。 *注意： *收到该轮的 362（PodcastRoundEnd）且没有 is_error 后，才记录这个ID *仅收到 360（PodcastRoundStart）或部分音频的轮次不计入
retry_info object​
连接中断后继续生成​
retry_task_id string​
待续传的原任务 ID，填写首次请求响应中的 session_id​
注意：续传会生成新的 session_id，但多次续传仍使用首次请求的值​
​
​
last_finished_round_id number​
最后完整接收的轮次 ID。​
注意：​
  • 收到该轮的 362（PodcastRoundEnd）且没有 is_error 后，才记录这个ID​
  • 仅收到 360（PodcastRoundStart）或部分音频的轮次不计入​

输入示例

export PODCAST_API_KEY='<YOUR_API_KEY>'

curl -N --request POST \
  'https://openspeech.bytedance.com/api/v3/podcast/sse' \
  --header "x-api-key: ${PODCAST_API_KEY}" \
  --header 'x-api-resource-id: volc.service_type.10050' \
  --header 'Accept: text/event-stream' \
  --header 'Content-Type: application/json' \
  --data-raw '{
    "action": 3,
    "use_head_music": false,
    "use_tail_music": false,
    "audio_config": {
      "format": "mp3",
      "sample_rate": 24000,
      "speech_rate": 0
    },
    "nlp_texts": [
      {"speaker":"zh_male_dayixiansheng_v2_saturn_bigtts","text":"你好，欢迎来到测试播客。"},
      {"speaker":"zh_female_mizaitongxue_v2_saturn_bigtts","text":"今天我们测试新的流式接口。"}
    ]
  }'
