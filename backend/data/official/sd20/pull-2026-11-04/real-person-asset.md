> 全部文档的索引见 [llms.txt](https://ark.volcengine.com/llms.txt)；在任一文档页面地址后追加 `.md` 可获取该页的 Markdown 版本。

> **说明**
>
> * 真人认证流程有一定概率**受光线、角度等影响，出现不通过的情况**，如若出现可引导艺人再次尝试
> * 出于安全考虑，补充素材时会进行人脸一致性检测，**有一定概率不通过**，建议上传**清晰的正面形象图片（** 视频一致性校验时，会对视频隔秒抽帧，全部通过一致性校验才会允许入库，因此视频中出现侧脸/多人等情况，会造成一致性校验不通过）
> * 出于对艺人权限的保护，便于艺人后续对自己的人像进行管理，真人认证当前须登录火山账号，**一个火山账号支持创建多个/多人真人人像**

<span id="c63e4bae"></span>
## 功能简介

为确保创作者能充分利用 Seedance 2.0 和 Seedance 2.5 强大的视频生成能力高效生成视频内容，同时规避 AI 生成内容的潜在风险，方舟推出了可信素材库。完成入库的素材将进入您的私域素材库，在视频生成中使用。
私域素材库支持录入**真人演员**素材（图片、视频或音频），通过**真人认证**从根源锁定肖像权归属，规避后续肖像权纠纷风险；真人演员仅需完成一次授权，后续新增妆造无需重复真人认证流程，大幅降低录入成本。
> * 方舟提供可公开使用的虚拟人像库，更多信息请参考[虚拟人像库](/docs/avatar-library)。

<span id="a3847afd"></span>
## 录入真人人像

真人人像库帮助您合规在 Seedance 2.0 和 Seedance 2.5 生成视频中使用真实人物作为演员，极大提升了 AI 生成视频的质量和制作效率。
您可在火山方舟体验中心生成人像资产录入邀约二维码。授权方（如艺人）可在移动端快速完成真人认证、上传本人素材，并授权您的账号使用其形象。授权完成后，您即可使用艺人上传并授权的有效人像素材生成视频。

填写资产名称（必填）和资产描述，并上传素材。
图片示例：

> **说明**
>
> **全身参考图要求**
> * 版式：竖版
> * 图片内容：人物全身正面图片

<div style="text-align: center">![](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/372f80d7ac3547bca195f4f5f1b59cb4~tplv-goo7wpa0wc-image.image)</div>

> **说明**
>
> **人脸特写图要求**
> * 板式： 竖版
> * 图片内容：人物正面无表情特写，肩部以上，人物面部占画面2/3左右

![](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/94dcbab909bd4020a92ea8e20d164d43~tplv-goo7wpa0wc-image.image)

格式要求：

> **说明**
>
> **图片**：
> * 格式：jpeg、png、webp、tiff、gif、heic、heif
> * 宽高比（宽/高）：(0.4, 2.5)
> * 宽高长度（px）：(300, 6000)
> * 大小：单张图片小于 30 MB
>
> **视频**：
> * 格式：mp4，mov
> * 分辨率：480p、720p、1080p、4K
> * 时长：单个视频时长 [2, 30] s
> * 尺寸：
>     * 宽高比（宽/高）：[0.4, 2.5]
>     * 宽高长度（px）：[300, 6000]
>     * 总像素数：宽×高 ∈ [407696, 8295044]
> * 大小：单个视频不超过 200 MB
> * 帧率（FPS）：[24, 60]
>
> **音频**：
> * 格式：wav、mp3
> * 时长：单个音频时长 [2, 30] s
> * 大小：单个音频不超过 15 MB
>
> 不同模型支持的输入音视频时长不同。建议在上传前记录上传音视频的时长，方便终端客户区分哪些素材可以在 Seedance 2.0 和 Seedance 2.5 系列模型中使用。

通过一致性校验后，素材入库。

> **说明**
>
> * 单个素材组支持传入一个真人演员的不同妆造素材，仅需在创建素材组时进行一次真人认证。每次上传素材将进行一致性校验，校验不通过无法入库。
> * 不支持向同一素材组传入不同人物素材。

**注意**：上传完成后，将自动授权二维码对应的账号使用该人像素材。

<span id="1e67bed0"></span>
#### **步骤三、素材使用方（如制作公司）**：接收授权人像

每位艺人将单独生成专属素材资产组（Asset Group），该艺人授权的素材将出现在对应资产组中，方便统一管理。

1. 在 [方舟体验中心](https://ark.volcengine.com/region:cn-beijing/experience/gen_video?model=doubao-seedance-2-0-260128) 的真人人像库中查看待接收授权素材，点击 **接收** 并确认风险提示。

![](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c930d02ee64946f9836aba1facc4f27f~tplv-goo7wpa0wc-image.image)

![](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/df310648a7c14ec7af7925f55ee1e826~tplv-goo7wpa0wc-image.image)

> **说明**
>
> 如选择 **拒绝**，则素材资产状态将变为 **已拒绝**，该资产将无法被使用。请谨慎操作。

2. 您可按授权状态筛选素材，还可使用自然语言或筛选器，查找需要的真人素材。

## 使用真人素材生成视频

您可在 [体验中心](https://ark.volcengine.com/region:cn-beijing/experience/gen_video?model=doubao-seedance-2-0-260128) 或使用 [视频生成 API](/docs/create-video-generation-task-api) 生成视频。
**体验中心**：可在体验中心直接使用真人素材生成视频。

> **说明**
>
> 资产实际可用状态需以 **详情页内展示信息** 为准。*（一致性校验不通过的素材当前也会在资产列表页展示）*

![](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f1046627745d49b7afc7f3b910203b41~tplv-goo7wpa0wc-image.image)

![](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/deba010aafcb493fbfd1f15126939115~tplv-goo7wpa0wc-image.image)

**视频生成 API**：

* 需先获取要使用素材的 Asset ID。
* 使用视频生成 API 时，可按 `asset://<asset_id>` 规则拼接素材 URI，在 API 中使用对应素材生成视频，具体信息请参考 [使用预置虚拟人像](/docs/seedance-portrait-asset-guide#preset-avatar)。

```JSON
            {
                "type": "image_url",
                "image_url": {
                    "url": "asset://asset-20260222234430-mxpgh"
                },
                "role": "reference_image"
            },
```
