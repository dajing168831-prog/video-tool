# Seedance 高级创作权益包购买说明

> 全部文档的索引见 [llms.txt](https://ark.volcengine.com/llms.txt)；在任一文档页面地址后追加 `.md` 可获取该页的 Markdown 版本。

Seedance 高级创作权益包（以下简称“权益包”）是面向使用 Doubao Seedance 2.0 和 Doubao Seedance 2.5 的企业用户推出的增值订阅服务，支持包年包月购买，提供更大容量的私域素材资产库、更高的 API 调用 QPM 以及企业级内容创作支持。

# 规则说明

**生效规则**：
* 包年订阅，购买后立即生效，到次年当日 23:59:59 失效。

> 举例：在 2026-04-18 购买包年权益包，权益将于 2027-04-18 23:59:59 到期。

* 按月订阅，购买后立即生效，到次月当日 23:59:59 失效。

> 举例：在 2026-04-18 购买包月权益包，权益将于 2026-05-18 23:59:59 到期。

**变更规则**：
一个火山引擎主账号同一时间仅能生效一个套餐。
* 升配：支持灵活升配，差价按剩余有效期折算，升配分为以下两类：

| 升配方式 |  | 新套餐有效期 | 补差价规则 |
| --- | --- | --- | --- |
| **月包升级为年包** | * 高级创作权益月包 > 高级创作权益年包 | 升配套餐购买后立即生效，到次年当日 23:59:59 失效 | 升配需补差价金额 = `新套餐年包价格 − 原套餐月包价格 ÷ 原月包总生效天数 × 套餐剩余时长`（即：支付新年包全价，并抵扣原月包剩余天数对应的价值） | \
|  | * Premium 版月包 > Premium 版年包 | 例如，您在 2026-04-18 购买高级创作权益月包，在 2026-05-01 升配为 Premium 版年包，则年包有效期为 2026-05-01 至 2027-05-01 |  | \
|  | * 高级创作权益月包 > Premium 版年包 |  |  | \
|  | * Premium 版月包 > 高级创作权益年包 |  |  |
| **高级权益包升级为 Premium 权益包** | * 高级创作权益月包 > Premium 版月包 | 升配套餐购买立即生效，至原套餐结束失效 | 升配需补差价金额 = `(升配套餐价格 - 原套餐价格) / 原套餐总生效天数 * 套餐剩余时长` | \
|  | * 高级创作权益年包 > Premium 版年包 |  |  |

* 降配：不支持从同周期高级创作 Premium 版降配至高级创作权益包，以及从包年套餐降至包月套餐。

**退订规则**：
订阅服务一经购买即视为确认，不支持退款。建议您根据使用需求选择合适的订阅套餐。
**续费规则**：
* 按年购买：单次最多购买 1 年权益，权益包到期前 30 天开始可续费。
* 按月购买：单次最多购买 3 个月权益，当前套餐剩余时长 + 新购套餐总时长不能超过 4 个月。

> **说明**
>
> 重要：请在权益到期前及时续费，避免影响业务运行。如需协助，请联系您的销售代表或技术支持。

**逾期规则**：
* 资源关停：逾期 0~15 天。

    * 素材数量配额及 API 限流降级至高级创作权益（Entry）。

    **注意**：如素材资产或素材资产组数量超出免费配额上限（最多 50 个素材资产组或素材资产），则无法新增真人素材。
* 不可使用 Assets API 创建新的素材资产组（Asset Group）或上传素材资产（Asset），已存在的素材资产可继续使用。
    * 不可升配。
* 资源回收：逾期超过 15 天。

    * 无法继续查询&使用素材，付费订阅期创建的素材资产及素材资产组将被删除（**已删除的素材资产及素材资产组无法恢复，务必提前做好数据备份**）：

        **注意**：付费订阅高级权益包之前以及权益包订阅到期后 15 天内上传的素材及素材资产组不会被删除。

    * 不可续费，如需使用需重新购买。

# FAQ

**Q：权益到期后，已上传的素材会被删除吗**？
A：逾期 15 天后，付费订阅期创建的素材资产及素材资产组将被删除，但付费订阅高级权益包之前以及权益包订阅到期后 15 天内上传的素材及素材资产组不会被删除，已删除的素材资产及素材资产组无法恢复，请务必提前做好数据备份。
