本文列出当前方舟文档提供的 Skill。​

Skill 列表​

​

Skill​功能​
ark-model-benchmark​评测方舟模型的 TTFT、TPOT、E2E 和缓存命中率，并生成评测报告​
ark-docs-assistant​分析模型升级或迁移方案，扫描项目中的模型引用并评估替换风险​
sd25-pe​优化 Seedance 2.5 视频生成提示词​
sd2-pe​优化 Seedance 2.0 视频生成提示词​

​

安装 Skill​

安装前需准备 Node.js 22.20.0 或更高版本，以及 npm。安装完成后，重新打开 AI Agent 会话再使用 Skill。​

ark-model-benchmark​

ark-model-benchmark 支持连通性检查、Prefix 前缀复用、多轮长上下文和完整测试，并在 reports/ 目录中生成 Markdown 报告和 PNG 图表。​

使用前需安装 Ark CLI 并完成 SSO 登录：​

​

bash

复制

npm install -g @volcengine/ark-cli@latest​

arkcli auth login volc-sso​

​

执行以下命令安装 Skill：​

​

bash

复制

npx --yes skills@latest add "https://arkdocs.tos-cn-beijing.volces.com/skills/" \​

 --skill ark-model-benchmark \​

 --yes​

​

安装完成后，使用自然语言触发。例如：​

​

text

复制

帮我压测一下方舟上豆包 Seed 2.0 Mini 模型的性能。​

​

有关评测模式、参数和报告说明，参见[模型接入指南（LLM） - 性能评测](https://ark.volcengine.com/region:cn-beijing/docs/ark/go-live-benchmark-guide)。​

ark-docs-assistant​

ark-docs-assistant 用于分析模型升级或迁移方案，也可以扫描代码项目中的模型引用，生成模型替换清单并评估迁移风险。​

该 Skill 优先使用方舟文档 MCP 获取信息；MCP 不可用时，会尝试使用 Ark CLI。方舟文档 MCP 的配置方法参见[方舟文档 MCP](https://ark.volcengine.com/region:cn-beijing/docs/ark/tutorials-mcp)。​

执行以下命令安装 Skill：​

​

bash

复制

npx --yes skills@latest add "https://arkdocs.tos-cn-beijing.volces.com/skills/" \​

 --skill ark-docs-assistant \​

 --yes​

​

安装完成后，使用自然语言触发。例如：​

​

text

复制

扫描当前项目，将目标模型升级为最新模型，先给出迁移清单，不要直接修改。​

​

有关模型迁移场景，参见[Seed-Evolving](https://ark.volcengine.com/region:cn-beijing/docs/ark/latest-model)。​

sd25-pe​

sd25-pe 可以处理文本、故事片段和多模态参考素材，并根据视频生成、关键帧、分镜、视频编辑、声音编辑或视频延长等任务组织提示词。​

执行以下命令安装 Skill：​

​

bash

复制

npx --yes skills@latest add "https://arkdocs.tos-cn-beijing.volces.com/skills/" \​

 --skill sd25-pe \​

 --yes​

​

安装完成后，在 AI Agent 对话框中输入：​

​

text

复制

/sd25-pe + 你的提示词内容​

​

该 Skill 只负责生成或优化提示词，不会自行提交视频生成任务。有关 Seedance 2.5 提示词写法，参见[Doubao Seedance 2.5 提示词指南](https://ark.volcengine.com/region:cn-beijing/docs/ark/seedance-2-5-prompt-guide)。​

sd2-pe​

sd2-pe 可以根据任务类型整理 Seedance 2.0 视频生成提示词中的主体、动作、场景、镜头、风格和素材引用关系。​

执行以下命令安装 Skill：​

​

bash

复制

npx --yes skills@latest add "https://arkdocs.tos-cn-beijing.volces.com/skills/" \​

 --skill sd2-pe \​

 --yes​

​

安装完成后，在 AI Agent 对话框中输入：​

​

text

复制

/sd2-pe + 你的提示词内容​

​

有关 Seedance 2.0 的模型能力和提示词规则，参见[Doubao Seedance 2.0 系列教程](https://ark.volcengine.com/region:cn-beijing/docs/ark/seedance-2-0)。​
