# 上传商业化版权

> 全部文档的索引见 [llms.txt](https://ark.volcengine.com/llms.txt)；在任一文档页面地址后追加 `.md` 可获取该页的 Markdown 版本。

版权方可以提交视觉版权或真人版权。平台审核通过后，相关版权可在授权范围内用于内容生成和商业化。

## 操作概览

1. 进入 **商用版权上传**，选择 **视觉版权** 或 **真人版权**。
2. 填写基础与展示信息，上传展示的封面图。
3. 完成商业与授权配置，真人版权还需关联形象并上传形象素材图。
4. 提交审核，在 **提交状态** 中跟踪结果。
5. 如果提交被驳回，根据审核意见修改后重新提交。

## 前提条件

- 使用已加入白名单的版权方火山账号登录。
- 上传视觉版权前需准备版权的基础信息、授权期限、允许生成范围和展示封面图。
- 上传真人版权前需准备人物基础信息、封面图以及一个或多个形象的 5 张参考图。

## 进入商用版权上传

进入 [开通管理](https://console.volcengine.com/ark/region:cn-beijing/openManagement?LLM=%7B%7D&advancedActiveKey=model) > **管理素材资产** > **版权方版权管理** > **商用版权上传**。

## 上传视觉版权

视觉版权适用于影视、游戏、动漫等 IP 版权。

1. 在 **商用版权上传** 页面选择 **版权提交**。
2. 在 **选择上传类型** 区域选择 **视觉版权**。
3. 填写基础与展示信息。

    | 信息 | 填写说明 |
    | --- | --- |
    | 版权类型 | 选择版权所属类型。 |
    | 版权名称 | 填写中文名称；可提示补充英文名称。 |
    | 版权描述 | 说明作品背景、版权内容等描述信息；可提示补充英文描述。 |
    | 封面图 | 上传用于版权库卡片展示的图片。 |
    | 生效起止日期 | 填写本次授权的开始日期和结束日期。 |

4. 填写商业与授权配置。

    | 配置 | 填写说明 |
    | --- | --- |
    | 允许生成范围 | 配置盈利性场景、非盈利性场景、兜底禁止场景的黑白名单。 |
    | 其他要求 | 补充版权使用场景的特殊要求。 |

5. 检查信息后，提交审核。

## 真人版权

真人版权适用于真人 IP 及其多个可授权形象。

1. 在 **商用版权上传** 页面选择 **版权提交**。
2. 在 **选择上传类型** 区域选择 **真人版权**。
3. 填写基础与展示信息。

    | 信息 | 填写说明 |
    | --- | --- |
    | IP 名称 | 填写公众人物或真人 IP 的名称。 |
    | 经纪公司（版权方） | 选择或填写版权所属公司。 |
    | 性别、年龄、身高、体重 | 按页面要求填写人物信息。 |
    | 版权库卡片封面 | 上传用于版权库卡片大图展示的定妆图。 |
    | 适用题材 | 选择现代都市、古装、悬疑刑侦、写实等适用题材。 |
    | AI 标签 | 用户对该真人版权进行检索的相关标签。 |
    | 版权描述 | 说明人物 IP、授权内容和使用要求。 |
    | 生效起止日期 | 填写本次授权的开始日期和结束日期。 |

4. 填写商业与授权配置。
5. 在 **关联形象** 区域添加一个或多个形象。
6. 为每个形象填写名称并上传参考图。根据需要调整形象顺序或删除形象。
7. 检查信息后，提交审核。

## 准备形象图片

关联形象的图片需满足以下要求：

- 格式：JPG、JPEG 或 PNG，PNG 支持透明背景。
- 大小：单张不超过 50 MB。
- 分辨率：长边不低于 1024 px。
- 比例：宽高比在 1:2 至 2:1 之间，推荐使用 3:4 竖图或 4:3 横图。
- 内容：使用原始高清素材，保持单人形象清晰、头部完整且无遮挡。

平台逐张校验批量上传的图片。符合要求的图片继续上传；不符合要求的图片单独显示失败原因，不影响同批次的其他图片。

## 查看提交状态

提交后，在 **商用版权上传** > **提交状态** 查看审核进度。页面支持按上传类型和审核状态筛选，也可以按名称或提交人搜索。

| 状态 | 说明 | 后续操作 |
| --- | --- | --- |
| 审核中 | 平台正在审核提交内容。 | 查看详情；如页面允许，可撤回提交。 |
| 已驳回 | 提交内容未通过审核。 | 查看审核意见，编辑后重新提交。 |
| 已通过 | 版权已通过平台审核。 | 查看已生效的版权信息。 |
| 已撤回 | 提交人已撤回本次申请。 | 编辑后重新提交，或删除记录。 |

页面仅开放当前状态可执行的操作。操作可能包括 **查看**、**编辑**、**撤回** 和 **删除**。
