# 自有版权申请加白与使用指南

> 全部文档的索引见 [llms.txt](https://ark.volcengine.com/llms.txt)；在任一文档页面地址后追加 `.md` 可获取该页的 Markdown 版本。

要使用自有版权申请加白及相关能力，您需开通高级创作权益包。具体信息请参考 [Seedance 高级创作权益包购买说明](/docs/seedance-2-0-purchase-guide?lang=zh)。

为了更好地支持版权创作，充分使用 Seedance 系列模型的视频生成能力，方舟提供**自有版权资产**管理能力。您可以在控制台通过：

1. **[体验中心](https://ark.volcengine.com/region:cn-beijing/experience/gen_video) > Seedance 系列模型 > 版权库 > 管理资产 > 版权 IP > 自有版权** ；

2. **[开通管理](https://ark.volcengine.com/region:cn-beijing/openManagement?LLM=%7B%7D&advancedActiveKey=model) > 管理素材资产 > 版权 IP > 自有版权。**

![自有版权申请入口](https://arkdocs.tos-cn-beijing.volces.com/images/resources/copyright-clearance-usage-guide-cn-entry-20260921.png)

有关申请表的具体信息，请参考下方**申请方式**章节。

以上两条路径访问自有版权资产管理页面，完成权利证明材料提交并通过审核后，您可使用相关内容用于后续创作。

# 1. 申请方式

## 1.1 选择您的自有版权类型

| **类型** | 说明 |
| --- | --- |
| **版权作品** | 包含影视、动漫、游戏等各类版权 IP，例如迪士尼、漫威、华纳兄弟、索尼等头部版权方旗下 IP。 |
| **演员形象** | 包含艺人明星，例如刘德华、杨幂、周杰伦等，不包括其过往曾经出演过的影视剧的场景和妆造。例如对周星驰个人形象版权申请，但其作品唐伯虎点秋香不支持申请，若申请请选择版权作品类型。 |

## 1.2 选择您的身份

| **身份** | **说明** |
| --- | --- |
| **版权方** | 这个作品的版权属于您的公司。 |
| **被授权方** | 您获得了授权，有权使用作品。 |
| **代客申请** | 该作品的版权归属或者被授权方是您的平台客户，申请加白仅支持推理接入点范围。 |

## 1.3 填写您的自有版权的基础信息

| **信息** |  | **说明** |
| --- | --- | --- |
| **名称** || 已获得授权或享有版权的版权作品 / 演员形象的官方名称，请确保名称和证明材料中的完全一致。 |
| **加白范围** | **账号范围** | 对当前账号的主账号及其下所有子账号加白，主账号下所有项目与接入点均可以调用相关内容进行视频创作。 |
| ^^ | **项目范围** | 对当前账号下的特定项目进行加白，加白的项目下的所有推理接入点可以调用相关内容进行视频创作。 |
| ^^ | **推理接入点范围** | 对当前账号下的特定推理接入点进行加白，仅加白的推理接入点可以调用相关内容进行视频创作。 |
| **加白时间** || 提交加白申请并通过的时间至您获得的授权有效期的时间范围（UTC+8）。该时间段内，您可以使用该版权作品 / 演员形象用于 Seedance 视频创作。 |
| **自有版权图片** || （可选）上传自有版权的形象图。例：角色图、海报、肖像照、作品截图等。支持 PNG、JPG，最多 9 张且单张不超过 10M。 |
| **自有版权描述** || （可选）简要描述自有的版权的内容、特征与使用注意事项，200 字内。 |

## 1.4 上传自有版权证明材料

| **类型** | **身份** | 需要上传的材料 |

# 2. 使用方式

版权资产审核通过且配置生效后，您可以根据业务需要选择以下两种调用方式（使用任意一种方式即可）。

## 2.1 通过私域虚拟人像素材库调用

将生成时需要使用的版权参考图或视频上传至私域虚拟人像素材库，获取 Asset ID 后发起调用。私域虚拟素材库与真人人像素材库共享高级创作权益包容量，具体上传及使用方式请参考 [私域虚拟人像素材库使用指南](/docs/private-virtual-avatar-library-guide-preview)。

针对**演员形象**和包含**真人人脸**的IP参考内容，推荐使用此方式。

## 2.2 直接通过 API 调用

### 2.2.1 默认策略

支持在您已完成授权的 **账号** 或 **账号+Project** 或 **账号+Endpoint** 级别控制版权生成的权限，**适用于大多数场景**。

直接调用API即可，**无需增加其他参数配置**。

### 2.2.2 自定义策略

**仅适用于 Dreamina Seedance 2.0 / Seedance 2.0 fast / Seedance 2.5 视频生成 API；Dola Seedream 5.0 pro / flash 图片生成 API。**

支持您在**每次请求**中控制是否有版权的生成权限，更细粒度区分，适用于 ToC 场景。

需要您在生视频 API 中增加请求参数。若未增加，则默认在配置维度（如账号维度）整体加白该版权。其他参数说明请参见 [创建视频生成任务 API](/docs/create-video-generation-task-api)。

### 2.2.3 请求参数

**moderation_options** `object`

配置内容审核策略。

---

**moderation_options.ip_mode** `string`

配置已备案版权的放行策略。

- `default`：默认策略。当前请求的版权放行策略与账号默认策略一致。

- `custom`：自定义策略。需输入当前请求支持放行的版权范围。

---

**moderation_options.ips** `string[]` `条件必选`

当 `moderation_options.ip_mode` 设置为 `custom` 时，需填写您在控制台已授权的版权 IP ID。示例：`ip-s-20260521163134-xxxxx`。最多支持传入 10 个。

![copyright-ip-id-cn.png](https://arkdocs.tos-cn-beijing.volces.com/images/resources/copyright-ip-id-cn.png)

取值规则：

- 不传或传入空数组 `[]`：本次请求不允许放行任何版权。

- 传入 1~10 个 IP ID：本次请求仅放行列表中显式声明的版权 IP，其他版权被拦截。

> **说明**
>
> - 列表中的版权必须是已通过平台备案的版权。未通过备案或不存在的版权会被拦截。

# 3. 常见问题

## 3.1 作为版权方和被授权方，在提交证明材料时有什么区别？

- 版权方：只需证明作品版权归属于本公司。

- 被授权方：需提供从原始版权方到本公司的完整授权链条，并确保授权范围、用途及有效期完全覆盖实际使用场景。

## 3.2 版权备案已成功通过，为什么生成时仍被拦截？

可能是由以下原因导致，请对照排查：

- **包含未备案或受限内容**：输入材料涉及其他未备案的版权作品、真人肖像或公众人物形象。

- **调用环境不匹配**：发起调用的账号、Project 或 Endpoint 与已完成版权配置的主体信息不一致。

- **素材库位置选错**：将版权参考图或视频误上传至“真人人像素材库”，而非“私域虚拟人像素材库”（应上传至后者）。

- **参考素材特征不清晰**：上传的参考图或视频画质较低或与原角色造型差异显著，导致模型未能成功识别出该备案资产。

**解决建议**：若触发拦截，请参照上述原因核对输入内容、调用配置与上传路径后重新尝试。如确认配置无误仍反复被拦截，请联系您的客户经理或技术支持团队。

## 3.3 提交版权证明材料后，什么时候可以使用？

提交材料不等于立即生效，需要等待材料审核通过后方可进行调用。

您可以在控制台通过 **“体验中心 > Seedance 系列模型 > 版权库 > 管理资产 > 自有版权”** 路径查看审核进度。当审核状态显示为“已加白”时，表示配置已正式生效。此时，您可以根据此前申请的账号、Project 或 Endpoint 维度，调用模型生成该版权的相关内容。

## 3.4 控制台的自有版权申请加白目前支持哪些模型？

- **Seedance 系列**：Seedance 2.5、Seedance 2.0（含 2.0、2.0 Fast、2.0 Mini）

- **Seedream 系列**：Seedream 5.0 Pro

不同模型间的版权规则继承逻辑由您的**授权维度**决定：

- **账号/Project维度**：同一账号/Project下的模型推理接入点默认使用相同的 IP 加白规则。

- **Endpoint 维度**：IP 加白仅对已申请加白的特定 Endpoint 生效。若后续新建了其他 Endpoint，需单独为新 Endpoint 提交加白申请。

## 3.5 我最多能申请多少个自有版权资产？

版权资产的总数没有限制，但单个账号每天最多可提交 **10 次**自有版权申请加白。

## 3.6 是否支持Seedream系列模型？

目前版权加白仅支持 **Seedream 5.0 Pro** 模型，具体适用规则如下：

- **已为 Seedance 系列配置（账号维度）**：若您已在账号维度为 Seedance 系列模型完成了版权配置，同一账号下的 Seedream 5.0 Pro 模型将**自动继承**该版权配置。

- **仅为 Seedream 5.0 Pro 配置**：目前控制台线上功能仅对已购买“高级创作权益包”的客户开放。若仅需为 Seedream 5.0 Pro 申请版权加白（不使用 Seedance 系列），无需购买高级创作权益包。您可以联系您的客户经理通过线下流程提交申请，并将配置维度限定至 Seedream 5.0 Pro 的 Endpoint。
